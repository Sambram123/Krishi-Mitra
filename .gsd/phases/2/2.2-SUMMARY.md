## Deliverables Created

1. **`backend/nlu/prompts.py`**:
   - `EXTRACTION_SYSTEM_RULES`: Strict role prompt with 5 dialect few-shot exemplars covering North Karnataka (*-aitri*), Old Mysore (*-kanri*), code-mixed English ("borewell ge subsidy"), unit traps (2.5 hectare, 20 gunta), and crop loss compensation.
   - `PHRASING_SYSTEM_RULES`: Phrasing constraints enforcing max 25 words, max 2 sentences, respectful Kannada (*ನೀವು*), zero speculative financial payouts, and single-field follow-up discipline.
   - `build_extraction_prompt`: Feeds utterance + confirmed profile JSON + missing slots (never the scheme catalog).
   - `build_phrasing_prompt`: Formats verified engine results for summary phrasing.
2. **`backend/nlu/providers/`**:
   - `__init__.py`: `NLUProvider` protocol and `get_provider(name)` factory.
   - `gemini.py`: Official `google-genai` integration with `gemini-2.5-flash`, schema-constrained output (`response_schema=ExtractOut`), temperature 0.1, and JSON MIME type.
   - `ollama.py`: Local offline fallback provider targeting `qwen2.5:7b-instruct` in JSON mode.
3. **`.env.example`**:
   - Configuration template for `GEMINI_API_KEY`, `NLU_PROVIDER`, and local Ollama endpoint.
4. **`backend/nlu/extractor.py`**:
   - `NLUExtractor`: Orchestrates extraction with retry loop on `ValidationError`.
   - `apply_guardrails`:
     - **Eligibility Firewall**: Detects forbidden leaked keys ("eligible", "benefit", etc.) and resets extraction.
     - **Evidence Grounding**: Bilingual district synonym verification against transcript to flag ungrounded slots.
     - **Unit Sanity**: Discards land size outside $[0.01, 100.0]$ acres.
     - **PII Redaction**: Detects and redacts 12-digit numeric patterns from transcripts and logs.
   - `process_turn`: Full pipeline returning validated extract, normalized profile fields, and guardrail warnings.
5. **`backend/tests/test_nlu_extraction.py`**:
   - 10 comprehensive tests covering unit sanity, evidence verification, PII redaction, firewall blocks, retry mechanics, and normalizer integration.
