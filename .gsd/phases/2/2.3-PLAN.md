       - Deterministic fallback strings for missing slots:
         - land_acres: "ನಿಮ್ಮ ಬಳಿ ಎಷ್ಟು ಎಕರೆ ಅಥವಾ ಗುಂಟೆ ಜಮೀನು ಇದೆ ತಿಳಿಸಿ."
         - crops: "ನಿಮ್ಮ ಹೊಲದಲ್ಲಿ ಯಾವ ಬೆಳೆಗಳನ್ನು ಬೆಳೆಯುತ್ತಿದ್ದೀರಿ?"
         - irrigation_type: "ನಿಮ್ಮ ಜಮೀನಿಗೆ ನೀರಾವರಿ ಸೌಲಭ್ಯ (ಬೋರ್ವೆಲ್, ಕಾಲುವೆ) ಇದೆಯೇ ಅಥವಾ ಮಳೆಯಾಶ್ರಿತವೇ?"
         - district: "ನಿಮ್ಮ ಜಿಲ್ಲೆ ಅಥವಾ ತಾಲೂಕು ಯಾವುದು?"
       - Deterministic fallback for eligibility summary when phrasing LLM fails:
         - Summarizes eligible schemes cleanly: e.g., "ನಿಮ್ಮ ವಿವರಗಳ ಪ್ರಕಾರ [ಯೋಜನೆಗಳ ಹೆಸರು] ಯೋಜನೆಗೆ ನೀವು ಅರ್ಹರಾಗಿದ್ದೀರಿ. ವಿವರಗಳನ್ನು ಪರಿಶೀಲಿಸಿ."
       - Disclaimer template for synthetic demo schemes and PM-KISAN exclusions.

    2. `DialogueManager`:
       - `__init__(extractor: NLUExtractor, evaluator: SchemeEvaluator)`
       - `select_follow_up_question(missing_slots: list[str]) -> str`:
         - Returns targeted Kannada prompt for the first missing mandatory slot.
       - `phrase_response(results: list[EvaluationResult], missing_slots: list[str], provider=None) -> str`:
         - If slots missing: return follow-up question.
         - If profile complete:
           - Attempt LLM phrasing via `provider.phrase()` with `PHRASING_SYSTEM_RULES`.
           - Enforce Hard Guardrails on LLM output:
             - Word count check (≤ 25 words). If exceeded, truncate or fall back to template.
             - Payout check (no rupee/₹ or payment guarantees e.g. "₹15,000", "₹6,000 ಖಚಿತ"). If violated, fall back to template.
           - If LLM throws exception or times out, seamlessly return template response.
       - `process_turn(session_id: str, state: ConversationState, user_utterance: str) -> dict`:
         - Orchestrates:
           1. NLUExtractor extracts & normalizes slots.
           2. Merges fields into `state`.
           3. Computes missing slots.
           4. If profile incomplete: generate follow-up question, do not run rules engine.
           5. If profile complete: convert state confirmed_profile to `FarmerProfile`, run `evaluator.evaluate_all(profile)`, generate phrased response.
           6. Record turn history and return payload `{reply_kn, evaluation_results, missing_slots, state}`.

    AVOID: Allowing the LLM to decide eligibility or invent documents.
    AVOID: Promising monetary compensation or payouts in phrased replies.
    AVOID: Interrogating multiple missing slots at once; ask for one field at a time.
  </action>
