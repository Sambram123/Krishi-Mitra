# Plan 2.2: LLM Providers, Prompts & Extraction Pipeline

<objective>
Wire the LLM extraction layer — system prompts with Kannada few-shots, Gemini and Ollama provider implementations, and the extraction orchestrator with validation, retry, and guardrails.

Purpose: This is where rural Kannada text becomes structured slots. The extraction pipeline must handle dialect variation, enforce schema constraints, and never let the LLM leak eligibility decisions.

Output: Working extraction pipeline that takes a Kannada utterance and returns a validated, normalized ExtractOut, with automatic Ollama failover.
</objective>

<task type="auto">
  <name>Build extraction orchestrator with retry, guardrails, and tests</name>
  <files>backend/nlu/extractor.py, backend/tests/test_nlu_extraction.py</files>
  <action>
    Create `backend/nlu/extractor.py` with `NLUExtractor`:

    1. `__init__(provider_name: str = None)`:
       - Reads `NLU_PROVIDER` from env (default "gemini")
       - Creates provider via `get_provider()`
       - Tracks 429/5xx count for failover

    2. `extract_with_retry(transcript: str, known: dict, missing: list[str]) -> ExtractOut`:
       - Calls provider.extract()
       - On `ValidationError`: retry ONCE with the error as correction
       - On second failure: return empty ExtractOut (safe default)
       - On provider error (429/5xx/timeout): increment counter, failover to Ollama if ≥3 consecutive

    3. `_apply_guardrails(extract: ExtractOut, transcript: str) -> tuple[ExtractOut, list[str]]`:
       Returns (cleaned_extract, warnings_list):
       - **Eligibility firewall**: if the raw JSON (before Pydantic) contained keys like "eligible", "benefit", "document", "scheme" — log violation, return empty extraction
       - **Evidence check**: for each non-None field in extract, do a fuzzy check against the transcript. If no evidence found (e.g., district="Dharwad" but "dharwad" not in transcript lowered), downgrade to inferred (add to warnings)
       - **Unit sanity**: if normalized acres outside [0.01, 100], flag and set land_size to None
       - **PII redaction**: scan transcript for 12-digit numeric patterns → log a warning (redaction happens at the logging layer)

    4. `process_turn(transcript: str, state: ConversationState) -> tuple[ExtractOut, dict, list[str]]`:
       - Full pipeline: extract → guardrails → normalize → returns (extract, profile_fields_dict, warnings)

    Create `backend/tests/test_nlu_extraction.py`:
    - Test extract_with_retry with mock provider (no real LLM call)
    - Test guardrail: eligibility firewall blocks extraction with "eligible" key
    - Test guardrail: evidence check flags ungrounded district
    - Test guardrail: unit sanity rejects 500 acres
    - Test guardrail: PII pattern detected
    - Test retry: first call raises ValidationError, second succeeds
    - Test retry: both calls fail → empty ExtractOut returned
    - Test normalize integration: ExtractOut with gunta → correct acres in profile dict
    - Test canonicalize integration: crops_local ["togari"] → ["Pigeon Pea (Togari)"] in profile dict
    - Mock-based tests only — no real API calls, no API key needed

    AVOID: Making real LLM calls in tests — use unittest.mock to patch the provider.
    AVOID: Silently swallowing errors — log every guardrail trigger and every retry.
    AVOID: Returning None from process_turn — always return a valid (possibly empty) ExtractOut.
