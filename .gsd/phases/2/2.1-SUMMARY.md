## Deliverables Created

1. **`backend/nlu/schemas.py`**:
   - `LandSize`: Pydantic v2 model with `value: float` and `unit: Literal["acre", "gunta", "hectare"]`, `extra="forbid"`.
   - `ExtractOut`: Pydantic v2 model representing narrow extraction schema with strict enums and placeholder stripping for `district`.
2. **`backend/nlu/normalize.py`**:
   - `normalize_land_size`: exact Python float conversion ($0.025 \times \text{Gunta}$, $2.471 \times \text{Hectare}$).
   - `canonicalize_crop` / `canonicalize_crops`: maps local Kannada synonyms (ತೊಗರಿ, ಜೋಳ, ರಾಗಿ, ಕಬ್ಬು, etc.) to canonical rule-engine names.
   - `is_land_size_sane`: checks $[0.01, 100.0]$ acre range guardrail.
   - `extraction_to_farmer_profile_fields`: transforms `ExtractOut` into `FarmerProfile`-compatible field mappings.
3. **`backend/conversation/state.py`**:
   - `ConversationState`: JSON-serializable session state model.
   - `merge_extraction`: conflict-quarantining merge policy; `None` never overwrites confirmed values; `crops` undergoes set union.
   - `get_missing_slots` & `is_profile_complete`: tracks the 4 mandatory fields (`land_acres`, `crops`, `irrigation_type`, `district`).
   - `add_turn`: rolling 6-turn history trimmer.
4. **`backend/tests/test_conversation_state.py`**:
   - 15 unit tests verifying all merge, conflict, and serialization invariants.
