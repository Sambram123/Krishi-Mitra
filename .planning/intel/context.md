## Topic: System architecture and component layout
- source: architecture.md (§1, §3)
- notes: The architecture decouples a **Perception & NLU (AI) layer** from a **Decision-making auditable rule engine** to prevent LLM hallucinations while preserving fluid voice conversations. Client subgraph: microphone audio in, client VAD, high-contrast visual feed (scheme cards & audit), audio player for synthesized Kannada. Voice pipeline subgraph: ASR gateway & pre-processing, Kannada speech-to-text (Bhashini / Sarvam AI / Whisper Large v3), Kannada TTS (Sarvam Bulbul / ElevenLabs / Bhashini). Backend subgraph (FastAPI core): FastAPI WebSocket/REST gateway, session & state manager (farmer profile context), entity & intent extractor (Gemini 2.5 Flash / GPT-4o-mini with few-shot Kannada), deterministic scheme rule engine (Python auditable logic), audit & explanation generator, vector & structured scheme DB (SQLite / JSON knowledge base), dialogue & audio response synthesizer. Data flow: mic → Opus/WebM stream → VAD → ASR gateway → ASR → Kannada text + English loanwords → FastAPI gateway → session/state manager → extractor → slots back to session manager → rule engine (fed scheme criteria from scheme DB) → verified eligibility results → audit/explanation generator (JSON decision tree + missing fields) → dialogue & audio response synthesizer → TTS (PCM/MP3) and UI (structured scheme cards & explanations).
- notes: Frontend: React + Vite + TailwindCSS (or vanilla JS/HTML5 SPA with glassmorphic styling). Key UI components: dynamic audio visualizer (pulsing rings via Web Audio API), live Kannada subtitles in Kannada script and transliteration, visual scheme accordion cards (status tags Eligible=Green / Under Review=Yellow / Ineligible=Muted; benefit highlight; "why you qualify" audit points; document checklist with checkboxes for Pahani, Bank Passbook, Aadhaar, Caste Certificate), and an emergency/kiosk action ("One-click call to Kisan Call Center 1551" / "Locate Nearest Raitha Samparka Kendra (RSK)").
- notes: LLM role per architecture.md: (1) extract structured JSON entities (district, land_size_acres, crops, irrigation_type, category, intent, query_need); (2) normalize localized vocabulary — "ತೊಗರಿ" (Togari) → Pigeon pea / Red gram, "ಕಬ್ಬು" (Kabbu) → Sugarcane, "ಹೊಲ / ಜಮೀನು" (Hola/Jameenu) → agricultural land, "ಗುಂಟೆ" (Gunta) → 1/40th acre, "ಪಹಣಿ / ಆರ್.ಟಿ.ಸಿ" (Pahani/RTC) → Record of Rights, Tenancy and Crops; (3) formulate empathetic spoken-form Kannada responses (max 2 concise sentences).

## Topic: Reference dataset rationale (why synthetic schemes)
- source: dataset_research.md (§1)
- notes: The hackathon guidelines mandate a hybrid test dataset of 2 Real Official Schemes and 3 Synthetic/Fictional Benchmark Schemes. Organizers include fictional schemes to (1) test whether the rule engine evaluates arbitrary strict rule branches rather than the LLM regurgitating web-scraped PM-KISAN summaries, (2) allow exclusion/boundary-condition auditing (e.g., drip pipe diameter limits, soil pH ranges, tractor HP brackets) without gazette debate, and (3) validate guardrails and disclaimers (the assistant must signal "This is a demonstration scheme for testing eligibility logic").

## Topic: Scheme rule catalog (5 benchmark schemes)
- source: schemes_knowledge_base.md (§1)
- notes: **PM-KISAN** (Real; Central Government of India). Purpose: income support for landholding farmer families. Benefit: ₹6,000 per annum in three 4-monthly installments of ₹2,000 via DBT. Eligibility: `is_landholder == True` (owns cultivable land in own name), `land_size_acres > 0.0`. Exclusions (mandatory check): institutional landholders; farmer/family member holding or held constitutional posts; former/present Ministers, MPs, MLAs, Mayors, Chairpersons of District Panchayats; serving or retired officers/employees of Central/State Government departments; all persons who paid Income Tax in the last assessment year; professionals (Doctors, Engineers, Lawyers, CA) registered with professional councils. Mandatory documents: Pahani/RTC, Aadhaar Card, Aadhaar-seeded bank account (NPCI active).
- notes: **PMFBY** (Real; Ministry of Agriculture & Farmers Welfare / Karnataka Samrakshane). Purpose: financial support and comprehensive crop risk insurance against non-preventable natural disasters. Benefit: claim payout based on calculated yield shortfall or localized damage. Eligibility: `crop IN ["Ragi","Pigeon Pea (Togari)","Jowar","Paddy","Cotton","Groundnut","Sugarcane","Maize"]`, `season IN ["Kharif","Rabi","Summer"]`, `is_notified_area == True` (Karnataka notified taluks/hoblis), `risk_type IN ["Drought","Excess Rainfall","Pest Attack","Flood","Hailstorm"]`. Mandatory documents: Pahani/RTC, Sowing Certificate (Village Accountant / self-declaration), Bank Passbook.
- notes: **Demo Micro-Irrigation Support** (Synthetic). Benefit: small/marginal farmers (≤ 5.0 acres) 90% subsidy; other farmers (> 5.0 and ≤ 12.5 acres) 70% subsidy. Eligibility: `land_size_acres >= 0.5 AND land_size_acres <= 12.5`, `has_water_source == True` (borewell, open well, or canal connection), `availed_drip_subsidy_last_3_years == False`. Mandatory documents: Pahani/RTC, Borewell/water source certificate, small/marginal farmer certificate (if claiming 90%). Disclaimer: demonstration test scheme for hackathon rule validation.
- notes: **Demo Agricultural Equipment Assistance** (Synthetic). Benefit: 50% subsidy up to a maximum cap of ₹1,00,000 for approved implements. Eligibility: `land_size_acres >= 1.0`, `requested_equipment IN ["Power Tiller","Rotavator","Sprayer","Weeder","Small Tractor"]`, `dealer_is_authorized == True`. Mandatory documents: Pahani/RTC, Aadhaar Card, quotation from authorized dealer.
- notes: **Demo Soil Improvement Support** (Synthetic). Benefit: ₹5,000 per hectare (max 2 hectares / 5 acres) for green manure, gypsum, and bio-fertilizers. Eligibility: `has_soil_health_card == True`, `soil_deficiency IN ["Low Organic Carbon","Saline","Alkaline","Acidic","Micronutrient Deficient"]`, `land_size_acres <= 5.0`. Mandatory documents: Official Soil Health Card, Pahani/RTC, bank account details.

## Topic: Dialectal and colloquial extraction mapping
- source: schemes_knowledge_base.md (§2)
- notes: Spoken rural phrase → canonical key → mapped value: ತೊಗರಿ (Togari) → `crop` → Pigeon Pea (Red Gram); ಕಬ್ಬು (Kabbu) → `crop` → Sugarcane; ರಾಗಿ (Ragi) → `crop` → Ragi (Finger Millet); ಜೋಳ (Jola) → `crop` → Sorghum (Jowar); ಕುಷ್ಕಿ (Kushki) / ಒಣಭೂಮಿ → `irrigation_type` → Rainfed / Dryland; ತರಿ (Tari) / ನೀರಾವರಿ → `irrigation_type` → Irrigated; ಗುಂಟೆ (Gunta) → `land_size` → converts to `0.025 * guntas` acres; ಹನಿ ನೀರಾವರಿ / ಡ್ರಿಪ್ (Drip) → `assistance_intent` → Micro-Irrigation; ಟಿಲ್ಲರ್ / ರೋಟವೇಟರ್ → `assistance_intent` → Agricultural Equipment; ಮಣ್ಣು ಪರೀಕ್ಷೆ (Mannu Pareekshe) → `assistance_intent` → Soil Improvement; ಬೆಳೆ ಹಾನಿ / ಒಣಗಿ ಹೋತು → `assistance_intent` → Crop Insurance (PMFBY).

## Topic: Voice-first paradigm vs "mic-on-a-chatbot"
- source: voice_interaction_design.md (§1)
- notes: Hackathon note quoted verbatim: "The main innovation should be the quality of the voice interaction—not merely adding a microphone to a generic text chatbot." Contrasts: response length (rolled-out 300-word policy text for 90 seconds vs 2-3 rhythmic sentences, full detail on cards); turn taking (must wait for robotic audio vs barge-in via Web VAD); vocabulary (formal textbook Kannada vs warm rural conversational Kannada); incomplete inputs (generic error "Missing land size" vs proactive in-context nudge); audio latency (6-9 seconds cloud roundtrips vs < 1.8 seconds target via streaming ASR + immediate LLM first-token generation + cached audio cues).

## Topic: Acoustic UX cues and prompt engineering
- source: voice_interaction_design.md (§4)
- notes: Instant acoustic earcons — soft rising chime when the mic starts listening, subtle "processing" sound while transcribing, low chime when eligibility is confirmed. Audio fallback/retry uses gentle in-language nudges when audio is distorted or tractor/wind noise dominates. Dialect normalization is handled by an LLM system prompt: "You are 'Krishi Mitra', a compassionate Kannada agricultural officer in Karnataka. Input will be rural spoken Kannada transcripts with colloquialisms (-aitri, -nodri, -kanri, gunta). 1. Extract: district, land_acres, crops, irrigation, assistance_needed. 2. Always confirm eligibility using only the verified rules passed to you. 3. Spoken Kannada responses MUST be maximum 25 words, respectful (respectful pronouns: -ರೆ, ನೀವು), and clear."

## Topic: Model capabilities registry (optional guidance)
- source: model_capabilities.yaml
- notes: Optional GSD guidance file; explicitly "for guidance only" and workflows must never depend on it. Capabilities: `thinking_mode` (extended reasoning), `long_context` (>100k tokens), `tools` (function/tool calling), `speed_tier` (fast <2s / standard 2-5s / reasoning >5s). Profiles: `fast_coder` (fast, no thinking, no long context, tools) best for quick edits/simple implementations/frequent iteration; `standard` (2-5s, long context, tools) best for most development, moderate refactoring, general coding; `reasoning` (thinking, long context, tools) best for architecture planning, complex debugging, security analysis. Phase recommendations: planning → reasoning; implementation → fast_coder; refactoring → standard; debugging → reasoning; review → standard.
